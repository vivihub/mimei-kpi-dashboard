🔧 セットアップガイド

未明シアター ダッシュボード × YouTube API 自動連携

STEP 1

Python をインストール

まだ Python が入っていない場合は python.org からインストールしてください（3.8以上）。

インストール確認（ターミナル / コマンドプロンプトで）:

python --version
STEP 2

必要ライブラリをインストール

ダッシュボードファイルと同じフォルダで以下を実行:

pip install google-api-python-client google-auth-httplib2 google-auth-oauthlib

または requirements.txt を使う場合:

pip install -r requirements.txt
STEP 3

Google Cloud プロジェクトを作成

Google Cloud Console を開いてください。

① 新しいプロジェクトを作成
上部の「プロジェクトを選択」→「新しいプロジェクト」→ 名前（例: mimei-dashboard）を入力 → 作成

② YouTube API を有効化
左メニュー「APIとサービス」→「ライブラリ」から以下を検索して有効化:

必須YouTube Data API v3
必須YouTube Analytics API

⚠️ 2つとも有効化が必要です。片方だけだとエラーになります。
STEP 4

OAuth クライアント ID を作成

「APIとサービス」→「認証情報」→「認証情報を作成」→「OAuth クライアント ID」を選択。

アプリケーションの種類: デスクトップ アプリ
名前: なんでも OK（例: mimei-dashboard）

作成後、「JSONをダウンロード」ボタンをクリック。

ダウンロードしたファイルを client_secret.json にリネームして、
スクリプトと同じフォルダに置いてください。

⚠️ OAuth 同意画面の設定も求められます。「外部」を選び、テストユーザーに自分のメールアドレスを追加してください。
STEP 5

スクリプトを実行

ターミナルでファイルが置いてあるフォルダに移動して:

python fetch_youtube.py

初回はブラウザが自動で開くので、YouTubeチャンネルと紐づいた Google アカウントでログインしてください。

✅ 完了すると token.json が作成され、次回からはログイン不要でデータ取得できます。
STEP 6

毎日の使い方

毎日1回実行するだけです:

python fetch_youtube.py

当月データだけを再取得するため高速です。全月を再取得したい場合:

python fetch_youtube.py --all

実行後、mimei_dashboard.html が自動で更新・ブラウザで開きます。

💡 Mac なら「自動化」アプリ / Windows なら「タスクスケジューラ」で毎朝自動実行にもできます。
ファイル構成

同じフォルダに置くファイル

📁 dashboard/
├── mimei_dashboard.html   ← ダッシュボード本体
├── fetch_youtube.py       ← データ取得スクリプト
├── client_secret.json     ← Google Cloud からダウンロード（STEP 4）
├── token.json             ← 初回認証後に自動生成
└── requirements.txt       ← ライブラリ一覧
トラブルシューティング

よくあるエラー

access_denied が出る
→ OAuth同意画面のテストユーザーに自分のメールを追加してください。

403 insufficientPermissions
→ YouTube Analytics API が有効化されているか確認してください。

収益が 0 になる
→ チャンネルが収益化されていない、またはデータ反映に2〜3日かかる場合があります。

quota exceeded
→ 1日のAPI利用上限（無料枠: 10,000ユニット）に達しました。翌日に再実行してください。
